# Agent modules

This directory contains integrations for AI agents and agent-oriented development tools. These modules are separate from ordinary programs because they represent an agent workflow rather than only a command-line or graphical interface.

- `agents.codex`: OpenAI Codex Home Manager integration and NixOS persistence for the user's `.codex` data.

Add future agent integrations here while keeping shared shell tools and ordinary applications under `modules/programs/`.
